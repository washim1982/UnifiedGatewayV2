## How to interpret the findings

**Confirmed** means the behavior is established from the current code; the validation table identifies which behaviors were also exercised. **Conditional** means the implementation permits the issue, but exploitation depends on a named setting, infrastructure exposure, or operating condition. It does not mean that the live deployment was found vulnerable. Severity reflects the stated impact and prerequisites, without assigning an unmeasured CVSS score. No Critical vulnerability was established in this review.
